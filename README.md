# KUBO Arquitectura y Construcción — Landing comercial

Landing estática con el catálogo de modelos de KUBO (KUBO 75, YATE, NAVE, COBIJO), línea de hospitalidad, obras filtrables y formulario de cotización.

- `index.html`: la página completa (HTML + CSS inline + un script mínimo para los filtros).
- `img/`: fotos extraídas del portafolio de KUBO.
